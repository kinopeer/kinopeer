# Adding a release to qBittorrent, and freeing up space for it

## Adding a release

Adding a release (`src/screens/AddReleaseSheet.tsx`, `FilePicker.tsx`): Kinopeer gets only the `.torrent` (preferred, so files can be picked) or magnet link from Prowlarr, then adds it to qBittorrent itself via `src/releases/addRelease.ts` with the `tmdb:<type>:<id>` tag, the `kinopeer:notify` tag when Notify when finished is on (`notifications.md` → Notifications), category, save path and options. Prowlarr's own download clients are not used. The free space for the warning comes from the shared poll through `useFreeSpace` (`src/torrents/useMainData.ts`), which renders only when that value changes, so the sheet and a long file list don't render on every poll; on a phone that poll runs only while the sheet is open, since nothing else on the releases screen uses it. Skipped files: the torrent is added stopped, those files get priority 0, then it starts. For a title with Name files for a media server on (`mediaNames`, a download default kept as the others are), `addRelease` takes `mediaNames` (the type, the title, the year and the release's name as the hint for a series' season), adds the torrent stopped, renames its files as `titleNames` says, then starts it unless it's paused, and throws `MediaNamesError` after starting it when a rename failed, or with `taken` when another torrent is in the folder naming would use (`folderTakenBy`, over every torrent `torrents/info` lists), for a series one with files where this one's would go or whose files it can't read (`filesTakenBy` over `torrentsIn`'s torrents' `getTorrentFiles`, `taken.shared`), which the sheet says as added but not named, naming that torrent. Once the sheet has the torrent's info hash, it asks qBittorrent whether it has it already (`getTorrents` with the torrent's ID, `torrentId` in `src/torrents/sameTorrent.ts`) and holds the form back until it answers, and a refused add (`TorrentRefusedError`: 409 from qBittorrent 5.2, `Fails.` before) asks the same, so the sheet can say whether the torrent is there and open it; not for certain from a magnet link with only a v2 hash (`MagnetLink.v2Only`), which doesn't name a hybrid torrent's ID. After adding, the app goes to `/` with `{ added: title }` in the location state for a toast. The releases list marks the releases qBittorrent has (`inDownloads` in `useReleases`): their info hashes' IDs (`torrentId`) against the torrents `useLastTorrents` has (`heldIds`, compared with `sameIds`, in `sameTorrent.ts`), so it starts no poll, asks `torrents/info` once only when the page has no torrents, and renders on a poll only when the releases it marks change; a marked card or row links to the torrent over the page (`IconLink`, `ButtonLink`) in place of Add.

Free up space (`src/screens/FreeUpSpace.tsx`, #580) is a step of the add sheet, opened from the low space warning or the file picker: the torrents of the shared poll (`useMainData`, so it polls only while the step has been opened), grouped and sorted by `groupForFreeUp` (`src/torrents/freeUpSpace.ts`: a torrent counts when its `content_path`, which follows qBittorrent's folder for incomplete downloads while an unfinished torrent is kept there (else its `save_path`, for one without metadata), is the default save path of `getSaveLocations` or under it, `isUnder`; what it has on disk is `onDisk`), its sort kept in the preferences (`freeUpSort`, `freeUpSortDescending`, apart from Downloads'), the counter by `countedSpace`. It deletes through `useDeleteTorrents` with `withFiles`, whose confirmation then says the files go rather than asking, and whose `onDeleted` hands it the torrents qBittorrent deleted. Once opened, the add sheet renders the step with every view, in the same place, so a delete that settles after Back still reaches it, and keeps what it freed where it counts (`withFreed`); `estimatedFreeSpace` adds that to qBittorrent's figure, marked as an estimate, while qBittorrent still reports the figure it was freed from, since qBittorrent measures the disk only every 30 seconds. The estimate is the add sheet's alone: `useFreeSpace` and the other places keep qBittorrent's figure.
